# LunaPlayer

LunaPlayer 是一个基于 Python 和 PySide6 的本地音乐播放器。界面采用深色工作台布局：左侧为导航栏，中间为页面区域，底部常驻播放控制栏。

- 解码统一走 PyAV（FFmpeg），输出交给 Qt `QAudioSink`，不依赖系统媒体框架
- 解码在独立线程中完成，重采样为 44.1 kHz / 立体声 / 16 位 PCM 后写入音频设备，避免阻塞界面

## 功能概览

### 播放

- 支持常见音频格式：`mp3`、`flac`、`wav`、`ogg`、`m4a`、`m4b`、`wma`、`aac`、`au`、`aiff`、`aif`、`opus`
- 播放 / 暂停 / 停止 / 上一首 / 下一首
- 进度拖动定位、音量调节、一键静音
- 播放模式切换：顺序播放、列表循环、单曲循环
- 空格键全局播放 / 暂停

### 当前队列

- 打开目录递归扫描音频文件并替换当前队列
- 打开文件追加到当前队列
- 支持拖拽文件或文件夹到窗口导入
- 拖拽调整队列顺序
- 多选批量移除，右键菜单支持播放、收藏 / 取消收藏、移除、查看详情
- 按绝对路径去重，避免同一路径重复加入
- 右侧详情面板显示封面、标题、艺术家、专辑、时长等信息

### 收藏

- 独立的收藏页面，可从队列右键收藏 / 取消收藏
- 支持拖拽调整收藏顺序、播放、移除
- 收藏列表持久化，歌曲文件缺失时自动跳过

### 播放列表文件

- 导入 `m3u` / `m3u8` 播放列表（相对路径按文件所在目录解析）
- 导出当前队列为 `m3u8`

### 会话持久化

- 自动保存当前队列到 `m3u8`
- 保存播放模式与上次定位到的歌曲
- 下次启动恢复到上次那首歌，但不会自动加载或播放
- 恢复时跳过已经不存在的文件

### 在线搜索与下载

- 支持在线接口搜索，可切换来源：网易云音乐、QQ 音乐、酷狗音乐
- 支持分页浏览搜索结果（最多 10 页）
- 结果支持多选，可批量加入当前队列或批量下载
- 双击搜索结果直接加入当前队列
- 下载为异步流式写入，多个任务可并行；实际文件格式会根据响应头和文件头自动识别
- 下载完成后自动去重加入当前队列
- 可在设置中开启"下载歌曲时同时下载歌词"，将同名 `.lrc` 与音频一起保存
- 一键打开下载目录

### 歌词与歌曲信息

- 桌面歌词窗口：无边框、置顶、半透明背景，当前行高亮、上下行渐变
- 自动读取与音频同名的 `.lrc` 文件（支持多时间戳行）
- 歌词窗口支持鼠标拖拽、锁定、右键调整字体大小与关闭
- 歌曲详情对话框展示封面与基础元数据
- 搜索页与收藏页同样提供详情面板

### 设置与系统集成

- 设置项：默认播放模式、默认音量、下载目录、下载歌词开关、歌词字体大小 / 透明度 / 颜色、关闭窗口时最小化到托盘
- 系统托盘：播放 / 暂停、上一首、下一首、退出，双击托盘图标恢复窗口
- 关于对话框与版本展示

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `Ctrl+O` | 打开目录 |
| `Ctrl+F` | 打开文件 |
| `Ctrl+I` | 导入播放列表 |
| `Ctrl+E` | 导出播放列表 |
| `Ctrl+D` | 打开收藏 |
| `Ctrl+,` | 设置 |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | 切换到当前队列 / 在线搜索 / 收藏 |
| `Ctrl+L` | 显示 / 隐藏歌词窗口 |
| `Ctrl+Left` / `Ctrl+Right` | 上一首 / 下一首 |
| `Ctrl+Q` | 退出 |

## 数据与配置位置

| 路径 | 内容 |
| --- | --- |
| `~/.lunaplayer/config.json` | 全部设置项 |
| `~/.lunaplayer/playlists/current.m3u8` | 当前队列 |
| `~/.lunaplayer/playlists/current.meta.json` | 会话状态（当前索引、播放模式等） |
| `~/.lunaplayer/playlists/favorites.m3u8` | 收藏列表 |
| `~/Music/LunaPlayer` | 默认下载目录（可在设置中修改） |

## 运行环境

- Python `3.10+`
- 依赖见 `requirements.txt`：`PySide6`、`av`、`mutagen`、`urllib3`

## 快速开始

### 1. 进入项目目录

```powershell
cd /path/to/LunaPlayer
```

### 2. 创建环境并安装依赖

```powershell
conda create -n smallplayer python=3.12
conda activate smallplayer
pip install -r requirements.txt
```

### 3. 启动应用

```powershell
python main.py
```

也可以直接运行：

```powershell
python app/main.py
```

## 常用操作

### 导入本地音乐

- 菜单"文件 -> 打开目录"会扫描目录并替换当前队列
- 菜单"文件 -> 打开文件"会把选中的文件追加到当前队列
- 把文件夹拖到窗口中会追加扫描结果
- 把文件拖到窗口中会直接追加

### 在线搜索

- 切换到"在线搜索"页面，输入关键字后回车
- 在"来源"下拉框中选择网易云音乐 / QQ 音乐 / 酷狗音乐
- 选中一条或多条结果后：
  - "添加选中到播放列表"加入当前队列
  - "下载选中"保存到下载目录并自动加入队列
- 双击单条结果可直接加入当前队列
- 使用"上一页 / 下一页"翻页浏览结果

### 收藏

- 在队列中右键歌曲选择"收藏"，或按 `Ctrl+3` 打开收藏页
- 收藏页支持拖拽排序，右键可播放、移除、查看详情

### 桌面歌词

- 按 `Ctrl+L` 或菜单"视图 -> 显示歌词窗口"打开
- 需要音频文件同目录下存在同名 `.lrc`
- 右键可锁定窗口、调整字体大小或关闭；字体大小、透明度与颜色也可在设置中预设

